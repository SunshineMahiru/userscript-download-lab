# 手工验收清单

自动化能证明产物可以执行、能挂载面板、能经管理器接口走完下载链路，但证明不了「在真实脚本管理器里装上去能用」。下面这几步只能在浏览器里做，做完把结果填进最后那张表。

## 前置

- 一个支持 `GM_xmlhttpRequest` 与 `GM_download` 的脚本管理器：Tampermonkey、ScriptCat、Violentmonkey 任一。
- Node 20 以上，仓库已克隆并执行过 `npm ci`。

## 步骤

1. 起合成站点：

   ```bash
   npm run serve
   ```

   终端应打印 `合成站点已启动：http://127.0.0.1:8080/`。浏览器打开该地址，应看到三个链接。

2. 安装脚本：管理器里新建脚本，把仓库根目录的 `userscript-download-lab.user.js` 全文粘进去保存。管理器应显示脚本已启用，匹配范围是 `http://127.0.0.1:8080/*`。

3. 打开 `http://127.0.0.1:8080/chapter/ch-1`。页面左侧应出现竖排的「实验面板」书签，浏览器控制台无报错。

4. 点击书签展开面板，点「解析本章资源」。列表应出现 5 项，状态行显示「已解析 5 项资源。」，底部按钮变为「下载选中（5）」。

5. 取消勾选任意一项，按钮应变为「下载选中（4）」，列表计数仍为「5 项」。

6. 点「下载选中」。浏览器应弹出 4 个文件的下载（或直接保存，取决于管理器的 `saveAs` 设置）。状态行显示「已提交 4 个文件到浏览器下载。」。

7. 重新勾选全部再下载一次。其中一条是 `课堂录像（分片）.m3u8`，若管理器不支持该类型，状态行应显示「1 项失败，首个原因：not_supported …」，其余 4 条仍完成。

8. 把书签拖到页面下方，刷新页面。书签应停在拖动后的位置附近（吸附误差不超过 16 像素）。

9. 关闭浏览器「允许站点存储数据」后重复第 8 步。书签应回到默认位置且不报错——存储不可用时退化为默认位置，这是预期行为。

10. 打开 `http://127.0.0.1:8080/`。点解析应提示「当前页面不是章节页」，而不是静默无反应。

11. 打开 `http://127.0.0.1:8080/slides-viewer`，面板应提示「已找到幻灯片序列，至少 6 页」。点「合成幻灯片 PDF」，状态行依次显示统计页数、逐页合成、写入 PDF，最后提示已保存。浏览器应下载一个 6 页的 PDF，打开后每页是一张幻灯片，页面比例保持 16:9。

12. 在无痕窗口或关闭站点存储后重复第 8 步。书签应回到默认位置且不报错——存储不可用时退化为默认位置，这是预期行为。

## 已知未覆盖

- 跨域 iframe 内的资源不在覆盖范围：当前实现只在顶层文档运行，不进子框架。
- 签名过期与签名篡改这两条只在自动化里验证过。手工走一遍需要等 5 分钟让签名过期，或用开发者工具改写 `Location` 里的 `exp`，不在清单内。
